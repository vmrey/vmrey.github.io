# 🖼️ 文章配图与图片资源库 (`assets/images/`)

用于存放文章中的架构图、流程图、UI 截图、插图、SVG 矢量图等。

## 📝 引用方式示例：

### 1. 在 Markdown 草稿中引用：
```markdown
![系统架构图](../assets/images/system-architecture.png)
```

### 2. 在 HTML 页面中引用：
```html
<img src="../assets/images/system-architecture.png" alt="系统架构图" loading="lazy">
```

### 💡 优化建议：
- 推荐使用 `.png`、`.webp` 或 `.svg` 格式；
- 建议单张图片尺寸控制在 1MB 以内，以获得最佳的首屏加载速度。
