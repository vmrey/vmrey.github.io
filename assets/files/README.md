# 📁 附件、文档与下载文件库 (`assets/files/`)

用于存放供读者下载的技术文档（PDF）、源代码压缩包（ZIP）、思维导图源文件（XMind, Draw.io）等。

## 📝 引用方式示例：

### 1. 在 Markdown 中提供下载链接：
```markdown
📥 [点击下载实战源码压缩包 (.zip)](../assets/files/demo-source-code.zip)
📄 [在线查看系统设计白皮书 (.pdf)](../assets/files/architecture-whitepaper.pdf)
```

### 2. 在 HTML 中提供带下载属性的链接：
```html
<a href="../assets/files/demo-source-code.zip" download class="file-download-link">
  📦 下载示例完整源码 (.zip)
</a>
```
