# 🎬 视频与动图演示资源库 (`assets/videos/`)

用于存放功能演示录屏、技术视频片段、操作演示（MP4, WebM 等）。

## 📝 引用方式示例：

### 1. 在 Markdown / HTML 中嵌入播放器：
```html
<video controls width="100%" style="border-radius: 8px; margin: 1.5rem 0;" preload="metadata">
  <source src="../assets/videos/demo.mp4" type="video/mp4">
  您的浏览器不支持 HTML5 视频播放。
</video>
```

### 💡 优化建议：
- 推荐使用 `.mp4` (H.264 编码) 保证全设备兼容；
- 录屏尽量压缩在 10MB 以内，超长高清视频建议上传至 B站/YouTube 并嵌入 iframe 播放器。
